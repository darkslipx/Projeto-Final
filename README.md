![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

Site institucional e de vendas da **SysOs**, empresa fictícia que oferece um sistema de **ordens de serviço e pedidos online** para pequenos negócios. Projeto final de curso de desenvolvimento web front-end (dez/2023).

## ✨ Funcionalidades

- **Home** — apresentação do produto, recursos e demonstração visual do sistema
- **Planos** — tabela comparativa com quatro níveis (Free, Básico, Padrão e Full) e opção de doação
- **Sobre** — história e missão da empresa e das soluções oferecidas (Food Commerce e MAPOS)
- **Login / Cadastro** — tela única com transição animada entre os formulários de entrar e registrar
- **Layout responsivo** — navbar vira menu *dropdown* (hambúrguer) em telas menores
- Link "Experimente Agora" para o sistema de OS open source [MAPOS](https://github.com/RamonSilva20/mapos)

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3** — Flexbox, media queries, transições
- **JavaScript** puro — manipulação de DOM (menu responsivo e alternância login/cadastro)
- **Font Awesome** para ícones

## ▶️ Como executar

Site estático, sem build:

```bash
git clone https://github.com/darkslipx/Projeto-Final.git
cd Projeto-Final
# abra index.html no navegador (ou use a extensão Live Server do VS Code)
```
